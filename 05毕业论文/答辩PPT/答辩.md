# 基于 FreeRTOS 的智能居家安防系统

## 毕业设计答辩

**答辩人：** 吴兆国 · **学号：** 20222042236 · **专业：** 自动化  
**指导教师：** 段霖 · **时间：** 2026 年 5 月

---

## 1. 研究背景与系统目标

- **风险场景：** 厨房明火、烟雾/燃气、门口异常接近、温湿度异常
- **传统不足：** 单路检测、仅本地声光、远程刷新慢
- **本系统目标：** 多传感融合 · 本地 OLED/声光 · 蓝牙/语音 · MQTT 上云 · RFID 门禁启动

> 可插入论文 **图 2-1** 系统总体架构图（感知—控制—交互—云端）

## 2. 裸机 vs FreeRTOS：为何需要操作系统？

| 维度 | 裸机前后台 | FreeRTOS（本设计） |
|------|------------|-------------------|
| 结构 | 主循环 + 中断 | **17 任务**，模块化 |
| 阻塞 | 传感/联网互相拖慢 | IPC 阻塞，调度切换 |
| 共享资源 | 串口/OLED 易冲突 | 互斥量 + 消息队列 |
| 报警 | 队列轮询易滞后 | 边沿 + 信号量，约 **50 ms** |

**结论：** STM32F407 + FreeRTOS + MQTT/OneNET

## 3. 总体方案与内核对象

- **17 任务：** 采集 / 显示 / 报警 / 门禁 / 蓝牙 / 语音 / ESP8266 / MQTT …
- **IPC：** 3 互斥 · 4 二值信号量（火/烟→蓝牙/语音）· 1 事件组 · 8 消息队列
- **流程：** 上电仅 RFID → 刷卡解锁 → 监测告警 → MQTT 周期上报

## 4. 项目模块总览

| 传感 | DHT11 · MQ-2 · LM393 · HC-SR04 |
| 交互 | OLED · 按键 · 蜂鸣器 · LED |
| 认证 | MFRC522 刷卡门禁 |
| 通信 | 蓝牙 5.0 · ASRPRO 语音 · ESP8266/OneNET |
| 存储 | AT24C02（卡号、报警距离） |

**概括：** 多传感 + 多通道交互 + 双远程 + 云端属性上报与下行控灯

---

## 5. 演示（一）传感器数据采集

- DHT11 → 队列 → 菜单 / 蓝牙 / MQTT
- 火/烟 DO 边沿 → `g_mutex_alarm` → 声光 + 信号量通知蓝牙/语音
- 超声距离与阈值比较 → 入侵检测
- OLED 单任务消费 `g_queue_oled`

**测试数据：** 声光约 5 ms · 蓝牙/语音约 50 ms

## 9. 项目总结

1. **17 任务** FreeRTOS 架构，模块解耦、长期运行稳定  
2. **火烟边沿 + 信号量** 报警链路，近场约 50 ms  
3. **RFID + EEPROM** 参数掉电保存  
4. **蓝牙 + OneNET** 双远程通道已打通  
5. 满足课程设计验收与论文第五章测试结论  

**局限：** 优先级均为 5 · WiFi 固定 SSID · 语音受噪声影响 · 未做 OTA
